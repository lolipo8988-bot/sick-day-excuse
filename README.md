# The Funniest Sick-Day Excuse — sick-day-excuse

A one-line entry for the make.fun bounty "The Funniest Sick-Day Excuse", where an AI judge compares sick-day excuses two at a time and ranks the line that gets the laugh and still gets the day off.

The line:

> Can't come in today — I'm so swollen and congested that Face ID keeps rejecting me. Apparently I have to get better before I'm authorized to be myself again.

No fever, no dog, no dead grandmother: the narrator is genuinely, visibly sick — so swollen and congested that their own phone's Face ID keeps rejecting them like a bouncer. The twist lands in the last clause, where getting better becomes a security clearance: you have to recover before you're authorized to be yourself again. 157 characters, one line.

## Run

```sh
python3 main.py
```

Writes the line to `/output/entry.txt` (set `ENTRY_OUTPUT_PATH` to redirect it for local runs). Deterministic: every run writes exactly the same bytes.
